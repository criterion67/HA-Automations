# Climate

**Hardware:** 15x Aqara sensors, Venstar thermostat, garage/bedroom/hall heaters

| File | Description |
|------|-------------|
| `rudy_s_heater_offline_alert_new.yaml` | Monitors garage heater plug. Alerts if offline. |
| `hvac_filter_change_reset_via_nfc_tag.yaml` | NFC tap resets filter counter and logs date. |
| `bathroom_exhaust_fan_*.yaml` | Fan control based on humidity readings. |
| `master_garage_climate_*.yaml` | Coordinates garage heater and ventilation. |
